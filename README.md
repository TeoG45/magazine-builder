# Imaginea Lumii — Revistă Săptămânală de Slow Journalism & Builder Online

Acest proiect conține structura completă a revistei **Imaginea Lumii** construită în **Astro**, gata pentru rulare pe localhost, împreună cu o secțiune de **Visual Builder** interactiv pentru crearea paginilor fără cod.

## Cum să rulezi proiectul pe calculatorul tău:

1. Asigură-te că ai instalat **Node.js** (versiunea 18 sau mai nouă) pe laptop.
2. Deschide terminalul în directorul dezarhivat al proiectului (`imaginea-lumii`).
3. Instalează dependențele rulând comanda:
   ```bash
   npm install
   ```
4. Pornește serverul de dezvoltare local:
   ```bash
   npm run dev
   ```
5. Deschide browserul și accesează adresa:
   * **Pagina principală a revistei:** `http://localhost:4321`
   * **Interfața Visual Builder (Drag & Drop admin):** `http://localhost:4321/admin/builder`
